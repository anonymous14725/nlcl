NLCL
An open-source research prototype

What if natural language could be the programming language?

NLCL turns instructions into semantic operations, applies them to a persistent intermediate representation, and generates code for different domains.

One intent, many domains

The prototype explores a workflow where sentences become semantic tokens, tokens become computational structures, and those structures can produce outputs for apps, Python, games, embedded systems, hardware, C++, 3D, and CAD. The core works offline with Python’s standard library; optional language-model backends can extend interpretation.

NLCL is an independent project shared to invite research feedback. It is not affiliated with or endorsed by Anthropic.
